# Xiegu_GPA100_RF_Band_Selector-
RF Sensing Interface for GPA100 HF Amplifier

This device allows nearly any transceiver to work with the GPA100.
1-20W of RF input from 1.6 to 56Mhz.
The assertion of PTT (LOW) samples the RF and sets the output key-voltage to the amp to select the band.
PTT-OUT is then asserted within 20ms.

So FX4CR, KX3, and other non ICOM and Xiegu rigs can work.
